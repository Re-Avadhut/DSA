Compile and run one program at a time:
javac ProducerConsumer.java
java ProducerConsumer

The numbered source filenames are intentional; compile each file directly or
compile the whole folder with a modern Java JDK.
Note: Java pipe streams demonstrate pipe-like communication between threads, not Unix pipes between separate processes.
