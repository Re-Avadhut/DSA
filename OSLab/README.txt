OS Lab Java Programs

Each Java file is a standalone program. Compile and run from a terminal:
    javac FCFS.java
    java FCFS

Use the class name matching the filename (for example, FCFS.java -> FCFS).
All programs use standard Java and should work with a modern JDK (Java 11+).

Included:
01 FCFS scheduling
02 Non-preemptive SJF
03 Non-preemptive Priority
04 Round Robin
05 Multithreading
06 Process/thread concepts (Java ProcessHandle and Thread; not a direct fork/exec/wait replacement)
07 IPC using PipedInputStream/PipedOutputStream
08 Producer-consumer using BlockingQueue
09 Readers-writers using semaphores
10 Dining philosophers using semaphores
11 Banker's algorithm
12 Paging address translation simulation
13 Segmentation address translation simulation
14 FIFO page replacement
15 LRU page replacement
16 Optimal page replacement
17 First Fit, Best Fit, Worst Fit memory allocation
18 File operations

Note: These are study implementations of common OS-lab topics, not guaranteed to match every college manual verbatim.
