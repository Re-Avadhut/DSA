BASIC LINUX COMMANDS — QUICK REFERENCE
pwd                 Show current directory
ls                  List files and folders
ls -l                Detailed listing
ls -a                Show hidden files
cd folder            Change directory
cd ..                Go to parent directory
mkdir demo           Create a directory
rmdir demo           Remove an empty directory
touch file.txt       Create an empty file
cat file.txt         Display file contents
cp a.txt b.txt       Copy a file
mv a.txt b.txt       Move/rename a file
rm file.txt          Delete a file
head file.txt        Show first 10 lines
tail file.txt        Show last 10 lines
grep "word" file.txt Search for text
wc file.txt          Count lines, words, bytes
chmod +x script.sh   Make a script executable
ps                  Show processes
date                Show date/time
clear               Clear terminal
man ls              Open command manual
